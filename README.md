# Student Grade Tracker

A simple Java console-based application developed during my CodeAlpha Java Programming Internship.

The Student Grade Tracker allows users to enter student details, calculate grades and results, view student records, calculate average marks, find the highest and lowest marks, and search for a student by roll number.

## Features

- Add multiple students
- Store student name, roll number, and marks
- Validate marks between 0 and 100
- Automatically calculate grades
- Calculate Pass/Fail result
- Display all student records
- Calculate average marks
- Find student with highest marks
- Find student with lowest marks
- Search student by roll number
- Menu-driven interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays
- Classes and Objects
- Constructors
- Methods
- Loops
- Conditional Statements
- Switch Statement
- Scanner for user input

## How to Run

1. Download or clone this repository.
2. Open `Main.java` in a Java-supported IDE.
3. Compile and run the program.
4. Enter the number of students and their details.
5. Use the menu to perform different operations.
